# 🚀 Sai Naman Gangiredla — Portfolio

[![TailwindCSS](https://img.shields.io/badge/Styled%20With-TailwindCSS-38bdf8?style=for-the-badge&logo=tailwindcss)](https://tailwindcss.com/)

A sleek, modern, fully responsive **developer portfolio website** built with **Next.js 14**, **App Router**, **TailwindCSS**, and **Framer Motion**.  
Designed to showcase my skills, projects, experience, and achievements in an elegant, interactive way.

---

## 🌟 Features

### 🎨 **Modern UI/UX**
- Clean & professional design
- Smooth animations using Framer Motion
- Fully responsive on all devices
- Glassmorphism & minimal aesthetic

### ⚛️ **Next.js & App Router**
- SEO-optimized pages
- Image optimization with `next/image`
- Route-based rendering with server components
- Lightning-fast performance

### 🖼️ Project Showcase
- Each project includes:
  - Live demo link  
  - GitHub repository link  
  - Tech stack badges  
  - Animated hover effects  

### 🧩 Reusable Components
- Navbar  
- Footer  
- Skill cards  
- Project cards  
- Contact section  
- Social link icons  

### ⚡ Performance Optimizations
- Automatic code splitting
- Image lazy loading
- Smart routing
- Minimal bundle size

### 📨 Contact & Socials
- Email
- LinkedIn
- GitHub
- Resume button  
All accessible from the “Contact Me” section.

## 🚀 Getting Started

### **1. Clone the repository**
```bash
git clone https://github.com/Sai-Naman-Gangiredla/PORTFOLIO
cd PORTFOLIO
```

### **2. Install dependencies**
```bash
npm install
```

### **3. Run the development server**
```bash
npm run dev
```

Your portfolio will be live at:  
`http://localhost:3000`

## 🌐 Deployment (Vercel)

This project is fully optimized for **Vercel**, and deploying is extremely simple.

### **Deploy in 5 seconds**
Click below:

🔗 **Deploy Now**  
https://vercel.com/new/import?s=https://github.com/Sai-Naman-Gangiredla/PORTFOLIO

### **Manual Deployment**
1. Go to **vercel.com**
2. Create an account (if not already)
3. Click **“Add New → Project”**
4. Select your repository  
   `Sai-Naman-Gangiredla/PORTFOLIO`
5. Click **Deploy**

Your live site will be generated instantly.

Live Demo:  
👉 **https://sai-naman-gangiredla-portfolio.vercel.app/**
